# Sphere of Kings — Investor Master Blueprint

**Package version:** v1.0 — 2026-11-03

This directory holds the deliverables prepared in response to the founder's instruction regarding the proposed **$100 million** Sphere of Kings capital-raising program.

## Deliverables

| # | File | What it is |
|---|---|---|
| 1 | [`SOK-Investor-Master-Blueprint-v1.html`](SOK-Investor-Master-Blueprint-v1.html) | The full master blueprint — 43 print-styled A4 pages. Open in Chrome/Edge and print → "Save as PDF" (or run `build-pdf.mjs`). |
| 2 | `SOK-Investor-Master-Blueprint-v1.pdf` | Generated by `node docs/investor-blueprint/build-pdf.mjs`. |
| 3 | [`EXECUTIVE-SUMMARY.md`](EXECUTIVE-SUMMARY.md) | Standalone executive summary for investor communications. |
| 4 | [`SOURCE-AND-ASSUMPTION-REGISTER.md`](SOURCE-AND-ASSUMPTION-REGISTER.md) | Line-by-line provenance of every material claim; tracks verified / management-provided / proposed / illustrative items plus the A-list of items requiring confirmation. |
| 5 | [`INVESTOR-READINESS-CHECKLIST.md`](INVESTOR-READINESS-CHECKLIST.md) | Everything required before external submission. Six blockers identified. |
| 6 | [`PITCH-DECK-OUTLINE.md`](PITCH-DECK-OUTLINE.md) | Recommended 14-slide structure for a standalone investor deck (not a substitute for the Blueprint). |
| 7 | [`build-pdf.mjs`](build-pdf.mjs) | Node + Playwright script that renders the HTML to a print-quality A4 PDF using the Playwright already installed in `nextjs/`. |

## How to produce the PDF

```bash
node docs/investor-blueprint/build-pdf.mjs
```

If Chromium is not yet installed for Playwright:

```bash
cd nextjs
npx playwright install chromium
cd ..
node docs/investor-blueprint/build-pdf.mjs
```

The output lands next to the HTML at `docs/investor-blueprint/SOK-Investor-Master-Blueprint-v1.pdf`.

## Brand system used

- **Typography:** Cinzel (display) + Inter (body), locally hosted in `nextjs/public/fonts/`. The Blueprint HTML references `../../nextjs/app/fonts.css` so that the Playwright render picks up the real brand type.
- **Palette:** investor-document palette (navy `#101827`, gold `#C6A15B`, warm-white paper `#F8F9FB`, charcoal body text, muted steel for secondary) — a professional complement to the SOK brand gold used sparingly as an accent.
- **Product imagery:** the Blueprint references the 36 approved product images in `nextjs/public/images/products/` rather than stock imagery.
